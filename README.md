# Марс 2050 — кабинеты экспедиций

Детские кабинеты учебной игры для GitHub Pages. Участникам не нужны аккаунты GitHub или ChatGPT и не нужна установка программ.

## Проведение

Ведущий открывает свой отдельный файл `Mars_2050_teacher_GitHub.html`. В начале игры пульт показывает ссылки «Альфы» и «Омеги». Передайте участникам ссылку своей команды и оставьте пульт открытым на всё занятие.

Дети рисуют карты, записывают ответы и оформляют заявки. Изменения автоматически передаются в пульт, где преподаватель принимает работы по очереди: Альфа, Омега, следующий этап. Расходы и оценки подтверждает преподаватель.

Основной компьютер штаба собирает общий проект. Работа остальных компьютеров также видна ведущему отдельно. Одновременного объединения нескольких карт в один документ нет.

## Соединение и сохранение

GitHub Pages хранит только общедоступные файлы кабинета. Обмен работами идёт через WebRTC; PeerJS Cloud помогает установить соединение, при необходимости используется его TURN-ретранслятор. Учётные записи и ключи сторонних облаков не требуются.

Пульт должен быть открыт и подключён к интернету. Полученные работы сохраняются в IndexedDB браузера ведущего. У детей есть местное сохранение и скачивание резервной копии. При временном обрыве открытая вкладка сохраняет изменения и повторяет отправку после восстановления связи.

Перед занятием проверьте соединение на компьютерах класса: школьная сеть может ограничивать WebRTC или сервис подключения. Нужны актуальные Chrome или Edge. Не закрывайте детскую вкладку до сообщения «Ведущий получил изменения» либо скачайте резервную копию.

## Что опубликовано

В репозитории находятся загрузчик детских кабинетов, клиент передачи и PeerJS 1.5.5 (MIT). Закрытый пульт ведущего, сведения финала, коды и работы участников не входят в публичный репозиторий. Ссылки комнат создаются случайно при запуске пульта; передавайте их только участникам занятия.

Для нового занятия в пульте начните новую игру: появятся новая комната и новые ссылки. Для продолжения используйте прежний файл пульта в том же браузере и сохраните данные браузера.

## Размещение

GitHub Pages публикуется через `.github/workflows/pages.yml`. Workflow загружает только явный список публичных файлов. В настройках Pages выберите источник GitHub Actions.
