# Марс 2050 — кабинеты экспедиций v6

Учебная игра на GitHub Pages. Детям не нужны аккаунты GitHub или ChatGPT и установка программ. Главная цель — подготовить обе колонии к пылевой буре: обеспечить воду, энергию и защиту людей.

## Проведение

Ведущий открывает отдельный файл `Mars_2050_teacher_GitHub.html`, передаёт ссылки Альфы и Омеги участникам и оставляет пульт открытым. Сравните короткий номер комнаты на пульте и у детей.

Задания появляются по этапам: высадка и ресурсная установка → укрытие и обязанности → разведка и договорённость → общий план защиты. Два случайных события открываются только после объявления ведущим. Пройденные карточки доступны в истории.

Название команды синхронизируется. Рисунки, ответы, заявки и готовность автоматически передаются ведущему. В пульте есть лента действий с временем и номером компьютера. Ведущий видит последнюю изменённую работу или закрепляет нужный компьютер. Общий план автоматически показывает принятые объекты и маршруты обеих колоний. Свободные рисунки разных компьютеров сохраняются отдельно; для итогового рисунка выберите основной компьютер штаба.

Постройки подтверждает ведущий. Повторная отправка не списывает ресурсы повторно. На карте есть координаты, компас, рельеф и точки разведки Р1/Р2. Выберите объект, щёлкните по месту, заполните назначение и отправьте заявку. До принятия значок можно передвинуть. Водосборнику нужен сектор льда, станции — открытая площадка, укрытию — кратер; другое место требует объяснения адаптации.

## Экономика

Каждая колония начинает с 5 воды, 5 энергии, 6 материалов и бесплатного посадочного модуля.

| Действие | Расход | Результат |
| --- | --- | --- |
| Солнечная станция | 2 материала | +2 энергии при запуске |
| Водосборник | 2 материала, 1 энергия | +2 воды при запуске |
| Укрытие / свой объект / улучшение | 2 материала, 1 энергия | Подтверждённый объект |
| Укрепление посадочного модуля после разведки | 2 материала | Модуль становится защитой от бури |
| Комплект восстановления после разведки | 2 материала | +1 вода, +1 энергия; один раз на колонию |
| Принятая разведка в миссии 3 | 1 вода, 1 энергия | +2 материала один раз |
| Жизнь колонии после миссий 2 и 3 | По 1 воде и энергии | Автоматическое обслуживание |
| Принятое спасение в финале | По 1 воде и энергии у каждой колонии | Запас на время бури |

Установки пополняют запас один раз при запуске. Для разведки нужны маршрут туда и обратно, риск и запасной путь. Ресурсы также могут меняться по событиям и согласованным передачам. При нуле ресурсов команда остаётся в игре и может обосновать аварийное восстановление.

После разведки и переговоров есть 3 минуты на последнюю подготовку: укрепление, восстановление или согласованную помощь соседям. Таймеры дают 93 минуты плюс время проверок. Рядом с запасами показываются будущие расходы на обслуживание, разведку и бурю, а также свободный остаток.

Финальный план заполняется по шагам: выбор принятого укрытия, маршрут при переходе, три действия с ответственными, риск и запасной способ. Ведущий собирает обе части на одной карте и может вывести её на проектор. Программа проверяет наличие подтверждённой защиты, места базы, пути к укрытию и запаса воды/энергии. Результат содержит конкретные причины готовности или недостачи.

План отвечает на четыре вопроса: где укрываются обе команды, кто что делает, как обеспечены вода и энергия, что делать при срыве основного способа. Баллы (до 20) и вывод о спасении фиксируются отдельно.

## Соединение и сохранение

GitHub Pages хранит публичный загрузчик. Работы передаются через WebRTC; PeerJS Cloud устанавливает соединение, при необходимости используется TURN. Пульт должен быть открыт и подключён к интернету. Перед занятием проверьте обмен на настоящих компьютерах класса: школьная сеть может ограничивать соединение.

Полученные проекты сохраняются в IndexedDB ведущего, у детей — в местном хранилище браузера. При обрыве открытая вкладка повторяет отправку. Перед закрытием дождитесь «Ведущий получил изменения» или скачайте резервную копию.

## Обновление

Закройте старые вкладки пульта. Сохраните обновлённый пульт вместо прежнего файла, с тем же именем и в том же месте, затем откройте в прежнем браузере. Это помогает сохранить доступ к данным прежней комнаты. Дети обновляют свои вкладки Ctrl+F5. Для другого занятия начните новую игру и раздайте новые ссылки.

## Что опубликовано

В репозитории только загрузчик, клиент кабинета и PeerJS 1.5.5 (MIT). Закрытый пульт, личные карточки, коды и работы детей не публикуются. Ссылки комнат передавайте участникам занятия.

GitHub Pages публикуется через `.github/workflows/pages.yml`; источник Pages — GitHub Actions. Workflow загружает явный список публичных файлов.
